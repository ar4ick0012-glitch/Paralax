# Parallax AI — preview

Telegram Mini App, static preview version. Runs entirely in the browser:

- signals replay recorded market candles (historical examples, no live quotes);
- chart analysis recognises candles on your screenshot locally;
- history and favorites are stored on your device only.

Recorded candles come from open MIT-licensed datasets, see `data/LICENSES.txt`.

Open `index.html` through GitHub Pages.
